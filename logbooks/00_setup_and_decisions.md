## Decisions

| Date | Decision | Why |
|---|---|---|
| 2026-11-02 | Download only `responses`, `subjects`, `benchmarks`, `items` (skip traces, assets, raw) | traces (108 GB) and assets (155 GB) are not needed; the core is 14.8 GB |
| 2026-11-02 | Per-file downloader from a saved API index (`data/hf_ft_index.json`) instead of `snapshot_download` | snapshot listing of 100k+ files stalled |
| 2026-11-02 | Do not use precomputed OpenAI embeddings (`measurement-db-embed`) | no OpenAI key at scoring time, so test items could not be embedded the same way |
| 2026-11-02 | Model family: offline prior + test-time hierarchical logistic random effects + Fisher-information acquisition | see `01_research.md` §3–4 |
| 2026-11-02 | Light analysis locally on CPU; embeddings and large training on Kaggle GPU | per user instruction |
